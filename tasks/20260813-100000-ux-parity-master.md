## Prompt

Track the effort to make Pyper's UX **indistinguishable from Wispr Flow**. This is a tracking task —
do NOT implement everything here; it coordinates the focused child tasks below.

Method for every surface:
1. Capture the Wispr Flow reference screenshot(s) for that surface into `tasks/assets/<child-id>/`.
2. Open our matching component and diff it against the reference — layout, spacing, typography, colors,
   copy, controls, empty/loading/error states, hover/active states, and animation/timing.
3. Implement until a side-by-side is indistinguishable. Verify with `/verify` and `npm run desktop`.

Surfaces → our components (each is its own child task):
- Onboarding (8-step wizard) → `apps/desktop/src/components/OnboardingFlow.tsx` — see the audit task.
- Dictation overlay / recording pill → `apps/desktop/src/App.jsx` (+ the overlay window).
- Control panel + settings → `ControlPanel.tsx`, `ControlPanelSidebar.tsx`, `SettingsPage.tsx`.
- Permissions flow → `ui/PermissionsSection.tsx`, `ui/MicPermissionWarning.tsx`.

As new surfaces appear, add a child task with `/task` (its own prompt + reference screenshots).
